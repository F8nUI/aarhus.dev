A meetup for developers building with Claude. Share workflows, demos, and ideas with the local community.

Each meetup features talks, live demos, and open discussion around Claude-powered development.

- **Workflow Demos:** See how others use Claude Code in their daily development — from prototyping to production.
- **Tool Integrations:** MCP servers, custom hooks, IDE setups, and automation pipelines with Claude.
- **Prompt Craft:** Techniques for writing effective prompts, CLAUDE.md files, and system instructions.
- **Show & Tell:** Bring what you've built. Short lightning talks and demos are always welcome.
