Leaving dependencies unmanaged can leave you with security issues and keep you from the new features that would make your code better. Susanne Bach Ladefoged Hou explains why managing external dependencies is a critical part of software development, the risks of ignoring it, and how Renovate can automate the chore into a seamless, time-saving process.

A morning meetup hosted by Systematic, with coffee and a light breakfast. Spaces are limited; registration is via Tech Hub Aarhus's TicketButler page.
