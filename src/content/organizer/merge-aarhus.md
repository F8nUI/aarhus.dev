merge aarhus is a community-driven event where Aarhus tech communities come together under one roof for a day. It is organised by the communities themselves — among them Aarhus .NET User Group, Rust Aarhus, Claude Code Meetup Aarhus, Aarhus Ruby Meetup, Swift Developers Aarhus, Co-coders, CoderGirls Aarhus, Aarhus C++ User Group and OWASP Aarhus — open to everyone, and free.
